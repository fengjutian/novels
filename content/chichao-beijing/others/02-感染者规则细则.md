# 《赤潮北境》感染者规则细则

**版本：** V1.1
**状态：** 全书硬性规则，不得违反
**用途：** 约束感染者的行为、能力边界、代价与弱点

---

## 〇、最高原则

> **每一种能力都必须有边界、代价和可观察的规律。**
> **感染者不能为了制造戏剧冲突而随意获得新能力。**

违反本原则的场景即为设定崩坏，必须重写。

### 0.1 类型定位：感染者题材占主导

本书从第五卷修订起，明确定位为：**以感染者为主要外部威胁的灾难小说**。制度、表格、新闻、边境与撤离仍然保留，但它们必须服务于感染者造成的生存压力，不能取代感染者主线。

以下规则为正文开发的硬性要求：

1. **因果主导。** 每章的核心冲突必须能追溯到感染者、疑似转化、污染食物或感染者造成的道路与资源变化。不得连续两章只处理文件而没有感染威胁进入人物行动。
2. **三章一组。** 任意连续三章至少包含：一场直接遭遇、一场转化或医学观察、一场感染者造成的撤离或资源后果。三项可以分布在不同章节，不要求每章都打斗。
3. **完整场景。** 重要感染者场面不得只用一两句带过。必须写出发现、判断、应对、失误或代价、事后确认五个环节；主场景建议不少于六百汉字。
4. **人物关联。** 每三场感染者戏中，至少一场涉及有姓名的人、熟悉的衣物或可追查身份。感染者不能长期只是无名黑影或远处人群。
5. **转化链条。** 每卷至少完整呈现一次从正常交流、发热、感知或姿势改变，到失去自主行为的过程。不得用“后来转化了”跳过人物关系和伦理选择。
6. **环境变化。** 连续感染者场景不得重复同一种解法。声音诱导最多连续使用一次；下一场必须改变至少一个变量：温度、地形、能见度、保护对象、撤退路线、弹药、伤员或时间限制。
7. **规则可见。** 人物只能通过现场观察逐步认识规则。正文先写现象和误判，再写暂时结论；不得由旁白直接背诵本细则。
8. **战斗有后果。** 每次交战或诱导至少留下一个持续后果，如道路关闭、伤员、设备损坏、身份失联、物资损耗或人物关系改变。清除感染者不能让场景自动复原。
9. **制度退居第二层。** 表格、报告与会议可以出现，但单章纯解释篇幅原则上不得超过三分之一。制度内容必须与正在发生或刚刚发生的感染威胁交叉推进。
10. **恐怖来自选择。** 感染者戏的重点不是数量堆叠，而是人物必须在救人、保持安静、封门、撤退、确认身份和处置转化者之间作出不可兼得的选择。

### 0.2 场景开发检查表

每个感染者主场景交付前检查：

- [ ] 感染者为何出现在这里，来路能否追查？
- [ ] 它遵守哪一型的速度、感知、温度与力竭规则？
- [ ] 人物最初是否存在合理误判？
- [ ] 本场与上一场相比，环境变量是否不同？
- [ ] 是否至少有一个具体人物承担后果？
- [ ] 场景结束后，路线、人数、物资或关系是否发生永久变化？
- [ ] 删除感染者后，本章是否仍能原样成立？若能，说明感染者仍只是装饰，必须重写。

## 一、病原体基础设定

### 1.1 命名

**学名（内部）：** 赤潮拟菌（*Pseudovibrio rubescens*，暂定）
**公众称呼：** 赤潮病、赤潮感染者

**命名来源：** 海洋生物大规模异常增殖使海水呈现红色，故名"赤潮"。

### 1.2 特性

| 项目 | 设定 |
|---|---|
| 灾难源头 | 日本福岛设施通过检修旁路违规排放的未达标混合核废水（架空事件） |
| 初始变异 | 复合污染使近海原有拟菌发生稳定变异，并在鱼、贝类、藻类体内富集 |
| 传播媒介 | 海洋生物组织（鱼、贝类、藻类为主） |
| 传播途径 | 食用 / 生食 / 伤口接触感染组织 |
| 潜伏期 | 3–14 天，平均 7 天 |
| 空气传播 | **无** |
| 接触传播 | **无**（体液接触不传播） |
| 血液传播 | **无** |
| 是否致命 | 100%（未发现治愈或长期共存个体） |
| 尸体是否感染 | **否**（感染者死亡后尸体不再传染） |
| 温度耐受 | 见下 |

### 1.2.1 固定因果链

> **违规排放未达标核废水 → 近海微生物与鱼类变异 → 变异组织进入水产链 → 人类感染并转化。**

- 核辐射本身不在人与人之间传播；人类不会因为站在海边、淋雨或靠近感染者而转化。
- 人类转化必须经过变异海洋生物组织：食用、生食加工，或伤口直接接触。
- 人体变化不是“辐射瞬间改造人体”，而是变异拟菌进入人体后造成神经、肌肉与骨骼重构。
- 早期常规辐射检测可以低于警戒值，因为真正被漏掉的是未经申报批次的核素比例、重金属与处理药剂组合，以及生物体内的富集结果。
- 最终证据必须同时闭合三条链：违规排放批次记录、鱼体污染与拟菌变异记录、患者暴露与组织样本。只发现其中一条，不得由人物提前宣布完整真相。
- 能锁定源头的关键指纹不是单一氚数值，而是违规批次特有的核素比例与处理药剂副产物；二者在排水口沉积物、宫城异常鱼体和首批患者组织中一致。

### 1.3 温度规则（贯穿全书，不可突破）

| 环境温度 | 感染体状态 |
|---|---|
| 30℃ 以上 | 活动能力极强 |
| 20–30℃ | 活动能力正常 |
| 10–20℃ | 活动能力下降，动作迟缓 |
| 0–10℃ | 大部分感染体夜间静止，白天迟缓 |
| -10–0℃ | 常规感染体（I 型）活动显著受限，群体移动基本停止 |
| -20℃ 以下 | I 型完全停止移动，堆积 |
| -30℃ 以下 | III 型仍可活动 |
| 冰雪覆盖 | 移动效率下降 60%，但**不停止** |

**关键规则：** 冬季北方能够守住，不是因为武器更先进，而是因为**气温**。

### 1.4 感知规则

感染者的感知机制基于**声波震动 + 体温红外 + 视觉**三通道。

- **听觉阈值极低**：足以捕捉 30 米外的心跳与脚步。这是主要的感知方式。
- **红外感知**：可感知体温，与背景温差越大越敏感。5 米内可感知。
- **视觉**：基本无效。它们的眼睛在感染后 72 小时内失去聚焦能力。
- **后果**：安静、静止、无体温的目标（如掩体后的蹲伏者）在 10 米外基本无法被发现。

### 1.5 痛觉与损伤

- 感染后痛觉大幅降低，但**不等于没有**。可以感觉到疼，只是不躲避。
- 骨骼密度上升约 20%，抗打击能力增强，但**关节处仍是弱点**。
- 可以进食（生肉优先），但进食不是必需——饥饿状态下可持续活动 20 天以上。
- 可以睡眠吗？**不能**。进入类似低功耗的静止状态，表现为"石化"，可持续数天。

## 二、四个类型

### I 型：游荡者（基准型）

| 项目 | 内容 |
|---|---|
| **数量占比** | 约 85% |
| **首次出现** | **第16章**（12/14 昌原市中央市场三名摊主）。**首次出现的三例是转化早期**，行为特征见下方"转化早期 I 型" |
| **外观特征** | 无显著外观变化。体温 38–39℃，眼白出血，瞳孔散大。皮肤无溃烂，无血污 |
| **移动速度** | 步行速度约 4 km/h。冲刺可达 10 km/h，维持不超过 30 秒 |
| **行为模式** | 无目的游荡。受到声波或红外刺激后朝刺激源移动。抵达目标后攻击 |
| **攻击方式** | 撕咬为主。四肢也会抓挠 |
| **智力表现** | 无。可被引诱。可被声东击西 |
| **群体性** | 单独行动时威胁低。超过 30 只聚集后会形成"潮涌"，形成连续攻击链 |
| **弱点** | **关节、颈椎**。命中即瘫。爆头射击有效但浪费弹药。燃烧有效但耗时 |
| **应对方式** | 集结点杀伤。单只交战几乎不需火力 |
| **代价 / 限制** | 关节损伤后行动能力大幅下降。在 -20℃ 环境下逐渐停止 |

**战术意义：** 这是最适合"防守"的类型。大量 I 型可以在固定阵地上用集火火力消灭。问题在于数量与地形。

**转化早期 I 型（第 16 章首次描写，必须与后期 I 型区分开）：**

| 项目 | 内容 |
|---|---|
| **意识** | **三人全部清醒。**这不是可选项——它是"转化"这个词能被用出来的前提 |
| **头部** | **三人共同：固定左偏约 15 度，不主动转向。眼球随物体移动** |
| **语言** | **保留，但只在一人身上完整。**七号摊主三问三对（姓名、住址、联系电话全部答对）；第二人能应答但只会摇头；第三人不能应答。**不得写成三人共同特征** |
| **移动** | 能自主行走，可被架走，无抵抗 |
| **攻击** | **无。** 奔跑/嚎叫/扑咬是 II 型特征，第 21 章才出现 |
| **体温** | 38.6–39.4℃ |

**硬约束：**
- 第 16 章**不解释转化机制**，也不给出病原学证据——章明欣填的是"感染性原因待排"，"待排"是她的个人措辞，不是法定分类
- **不得提前到第 16 章之前。**第 13–15 章零转化个体
- **第 14 章急诊走廊那个陪护（眼睛跟着手动、头不转）是未转化患者**，异常来自高热与脱水，属可逆。**他不是第 19 章那个无名陪护**——第 19 章那个人是院感科八人名单里的第八个，无姓名无电话，从未登记。两人同在 12/10 夜的蔚山某医院急诊走廊，是两个不同的人。**这一区分不可合并，也不可在任何一方删掉**
- 第 16 章的三人**没有一个是第 14 章那 40 例里的**——这是信息延迟第一次造成"先有转化、后有病例表"的错位
- **第 19 章那个人不写死。**正文只写"眼睛跟着你，头往左偏十五度"，不写体温、不写应答能力、不写攻击性。**第二卷不得给出一个把他归入某一型的句子**

### II 型：猎行者

| 项目 | 内容 |
|---|---|
| **数量占比** | 约 10% |
| **首次出现** | **第21章（12/21 釜山港 7 号泊位事件中被分离确认）**。**II 型是本书第一个有战术结论的类型** |
| **外观特征** | 四肢肌肉异常发达，关节反向弯曲。体温 40–41℃。牙龈暴露 |
| **移动速度** | 步行 6 km/h。冲刺 28 km/h，**维持 3–6 分钟后必须静止休息 30 分钟以上** |
| **行为模式** | **有方向感**。会朝目标持续追踪 2–4 公里。中途失去目标后原地搜索 10–20 分钟 |
| **攻击方式** | 扑击。四肢并用。可以在墙上短暂攀爬（约 3 米） |
| **智力表现** | 有预判。会包抄。会使用简单的地形掩护 |
| **群体性** | 通常单独行动。**不参与群体聚集** |
| **弱点** | **冲刺后是绝对弱点**。静止 30 分钟期间几乎无法移动，肌肉在乳酸堆积状态。静止时关节仍可被攻击。**必须等它停下来才能打** |
| **应对方式** | **引诱至空旷地带 → 等待其力竭 → 集火击杀**。绝不在它冲刺时正面交战 |
| **代价 / 限制** | 高速移动造成的肌纤维撕裂**无法修复**。第 5 次冲刺后会出现自发性肌肉断裂，此后速度大幅下降。第 10 次冲刺后基本失去移动能力 |

**战术意义：** 这是最危险的类型。它决定了"不能被动防守"——被动防守会被它突破。

**剧情功能：**
- 第21–30章：让韩国军方第一次意识到"数量优势无效"
- 第31–45章：追击战、突围战的主要威胁
- 第58–62章：两江道山区的主要威胁
- 第92–105章：国际调查期间的追击威胁

### III 型：耐寒者

| 项目 | 内容 |
|---|---|
| **数量占比** | 约 4% |
| **首次出现** | 第76章（春季确认） |
| **外观特征** | 体表皮下脂肪层增厚，皮肤呈灰紫色。体温 34℃（**低于正常人**）。毛发脱落 |
| **移动速度** | 步行 3 km/h。**在 -30℃ 下仍可维持 3 km/h**。无冲刺能力 |
| **行为模式** | **极度迟缓但不停**。感知范围缩小至 5 米。以恒定方向移动，不因刺激改变方向 |
| **攻击方式** | 抓扯。力量大但速度慢。需 10–15 秒才能完成一次有效撕咬 |
| **智力表现** | 无。但**行为最难预测**——它们不追人，只是走。走的方向与人群逃往的方向往往重合 |
| **群体性** | 大规模沿同一方向移动。形成"缓慢的墙" |
| **弱点** | **关节（极度脆化）**。在低温下组织变脆，一击即断。但需要瞄准 |
| **应对方式** | **不主动交战**。挖掘壕沟、设置障碍、封锁路线。它们不会试图翻越障碍 |
| **代价 / 限制** | 在 **15℃ 以上环境中 48 小时内失能**。无法恢复正常体温。在 **-10℃ 以上环境中组织加速坏死，行动持续下降**。它们**不是永动机**——它们在慢慢死，只是死得慢 |

**战术意义：** 这是一个**时间性威胁**。春暖花开之后，气温越过 15℃，它们会在 48 小时内集体失能。这是人类唯一的天然窗口。

**剧情功能：** 第76章引入，立刻改变整个冬季防御的逻辑——因为它们不遵守"冷 = 停"的规则。这逼着中国东北在春天打一场"必须主动进攻"的仗。

### IV 型：引群者

| 项目 | 内容 |
|---|---|
| **数量占比** | **约 1% 或更少**（约为 I 型的 1/80） |
| **首次出现** | 第105章（联合防御讨论期间首次发现） |
| **外观特征** | **体型极小**。身高不足 1.2 米。极度瘦削，肌肉几乎消失。体温 41℃。眼窝深陷 |
| **移动速度** | 步行 1 km/h。**无法奔跑**。爬行速度 2 km/h |
| **行为模式** | **不参与进攻。永远在群体后方或下方。** 会停留在高处（屋顶、山脊、树冠、车顶） |
| **攻击方式** | **本身无攻击能力**。牙齿咬合极弱 |
| **智力表现** | **这是全书最需要谨慎处理的设定。见下方机制说明** |
| **群体性** | 与群体异常聚集、迁移直接相关 |
| **弱点** | **极易击杀**。一枪即死。它没有任何自保能力 |
| **应对方式** | 优先击杀。但**击杀它不等于群体停止**——见机制 |
| **代价 / 限制** | **离开群体 72 小时后开始衰竭，第 5–7 天死亡** |

#### IV 型的机制说明（严格遵守，不得写成精神控制）

**禁止写法：** IV 型拥有心灵感应、可以控制其他感染者意志、可以发出指令让感染者服从。

**允许写法与正确机制：**

IV 型不具有任何超自然能力。它的作用基于三个可观察的生物化学机制：

**机制一：高频振幅信号**
IV 型在聚集状态下会持续发出人耳可闻的低频震荡（约 15–20 Hz）。这个频率接近人体下颚与耳蜗的共振频率。

> **效果：** 其他感染者在接收该信号后，**对其他刺激的响应阈值被暂时降低**（原本 30 米可感知的声音，在信号覆盖下变成 8 米）。它们不是"服从命令"，而是"变得容易被惊动"。

**机制二：接触转移的信息素样挥发物**
IV 型体表分泌一种高浓度蛋白类挥发物。该物质通过空气扩散，在密闭或半密闭空间中可在 30 分钟内形成有效浓度。

> **效果：** 使周围感染者的**群体认同阈值降低**——原本会散开的个体，会主动靠拢。

**机制三：体温差**
IV 型体温 41℃，明显高于其他感染者。这在热成像上形成一个稳定的"热点标记"。

> **效果：** 其他感染者被 30 米内更强的热源吸引时，会**优先向 IV 型方向偏移**。这是"跟随"而非"命令"。

**综合效果：**
当 IV 型存在时，群体的**自发聚集倾向**被显著放大，散开倾向被压制。这解释了为什么某些区域会出现"看起来像有指挥"的迁移行为。

**为什么杀死 IV 型有用但不够：**
- 杀死 IV 型后，信号消失，群体阈值**需要 4–6 小时才能恢复**。这个窗口期是防守反击的最佳时机。
- 但只要该区域内还有其他 IV 型，聚集会重新形成。
- **因此真正的战术目标是：清除区域内全部 IV 型，而不是阻止群体移动。**

**这个机制带来的战术推论（必须贯穿第105章之后）：**
1. 防御方从"阻止群体通过"转向"优先猎杀 IV 型"
2. 需要能够穿透混乱群体、瞄准小型目标的精确火力与侦察
3. IV 型占据制高点 → 需要制高火力与观察哨
4. 短期清除不可能 → 需要分区域逐个清除 → 决定了最终防御战必须分区进行

**剧情功能：**
- 让最终防御战从"守住一条线"升级为"清剿一片区域"
- 提供具体可操作的战术目标，避免"打怪兽"的空洞感
- 让 IV 型的存在成为联合防御体系中"必须共享情报"的直接理由

## 三、类型判定规则（写作时必须可判断）

面对一个未知感染体，按以下顺序判断：

```
问 1：能否持续冲刺超过 5 分钟？
  ├─ 否 → 问 2
  └─ 是 → II 型（猎行者）

问 2：能否在 -30℃ 下保持活动？
  ├─ 否 → 问 3
  └─ 是 → III 型（耐寒者）

问 3：身高是否不足 1.2 米且不参与进攻？
  ├─ 否 → I 型（游荡者）
  └─ 是 → IV 型（引群者）
```

**注意：** 类型是**固定**的，不会中途转化。感染时是什么类型，就是什么类型。这一点必须严格遵守——不会出现"III 型突然获得 II 型能力"。

**判定写不出来的情形（2026-10-26 补记，见第 119 章）：** 判定必须**当场可做**，否则写"写不出来"，**不许凭现象替代判定**。三种情形会写不出来：

1. **问二测不了**：新上线的监测点没有冬天的记录，−30℃ 这一问无法实测（参照第 77 章"等到十月就能测了"）。第 119 章的四号监测点就属于这一种——正文写"**问二：这个点上没有冬天的记录**"，于是**类型判定写不出来**，这一条进"不能推的"那一栏。
2. **问一只是"没看见"**：只观察了四十分钟，个体没冲刺，只能写成"四十分钟里没有过"，**不能写成 II 型或任何排除结论**。
3. **体表面积/分辨力不足以分辨**：热成像分不清小型个体（见第 113 章"漏计"），计数与判型是两件事。

**为什么这一条要写进细则：** 第 76、105、112、117、118 章的判定都能当场做（问一当场看，问二有同一个点去年冬天的记录或当晚实测），第 119 章第一次出现"问二测不了"的新监测点。**正文里出现类型时，读者要能顺着问句找到依据；找不到依据时，正确写法是"判定写不出来"，不是"看起来像哪一型"。**

## 六、写作禁区清单

以下写法在本书中**严禁出现**：

- [ ] 感染者突然获得未记录的感知能力（心灵感应、透视、预知）
